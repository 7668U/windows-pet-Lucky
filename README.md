# Neon Spider 赛博霓虹蛛宠 (v2.5 · 360° 全向转向与真蛛解剖版)

基于原生 **Win32 32-bit Per-Pixel Alpha (`UpdateLayeredWindow`) + 360° 局部空间逆运动学 (IK) + 6 足交替三足步态 + 口器触肢引擎** 打造的 Windows 赛博朋克桌面宠物。

视觉完全忠实于俯视原画 [`reference.png`](./reference.png) 的真实蜘蛛解剖结构：
- **方形头胸部（真·头部，[`assets/body.png`](./assets/body.png)）**：全身旋转轴心，前缘嵌有发光护目镜，承载 **6 条双线 PCB 渐变荧光步行足**（前足 `L3/R3`、中足 `L2/R2`、后足 `L1/R1`）与嘴边一对灵动的**口器小手触肢**（`L4/R4`）；
- **六边形赛博腹部（背甲，[`assets/head.png`](./assets/head.png)）**：内嵌动态滚动 HUD 代码面板，通过细腰枢轴挂接在头胸部后方，转向与疾跑时自带重量感惯性滞后摆尾（`abdomen_wag_deg`）。

## 快速启动

- **日常使用（无黑框后台启动）**：直接双击 [`start_pet.bat`](./start_pet.bat)
- **命令行启动 / 指定初始缩放**：
  ```powershell
  py -3 pet.py --scale 0.42
  ```
- **自动化端到端实窗自检**：
  ```powershell
  .\start_pet.bat --self-test
  ```

## 键鼠与菜单交互指南

| 操作 | 效果 |
| :--- | :--- |
| **自主巡航 / 跟随转向** | 先原地踩交替三足小碎步调转头朝向对准目标（腹部惯性摆尾），再沿正前方弧线爬行，零螃蟹横滑 |
| **鼠标靠近** | 蜘蛛保持原地不动，自动踩小碎步转过头注视光标，两只嘴边小触手（`L4/R4`）高频探路互动 |
| **左键单击** | 护目镜眨眼 + 靠近点击侧的真前足（`L3` 或 `R3`）好奇轻敲桌面 |
| **左键按住 / 拖动** | 任意朝向拎起零跳变，6 条机械步足与 2 只小触手按屏幕拖拽反方向惯性拖尾并受屏幕重力自然下垂；松手后落地缓冲回弹 |
| **左键双击** | 随机触发一项 360° 招牌特技动作 |
| **鼠标滚轮上下** | 实时无级放大 / 缩小桌宠体型（`0.26x ~ 0.78x`） |
| **鼠标右键** | 弹出原生中文控制菜单（见下表） |
| **`Esc` 键** | 立即退出桌宠（需先点击一下桌宠使其获得焦点，或直接用右键菜单退出） |
| **点击外圈微光空白处** | 自动鼠标穿透（`Alpha < 22`），不遮挡桌面图标与底部窗口点击 |
| **多显示器跨屏漫游** | 自动识别所有已连接显示器（含不同分辨率 / 混合 DPI / 错位高度并热插拔刷新），支持自主跨屏巡逻、跨屏跟随鼠标与直接拖拽到副屏 |

### 右键菜单功能
- **动作点播（全部朝向当前正前方施展）**：
  - `前足挥手打招呼`：真前足 `L3/R3` 伸向前方招手，嘴边小触手欢快摆动
  - `双前肢警戒威慑`：双前足大幅前张高频震颤 + 口器双触肢如螯牙外扩 + 机身蓄势后仰
  - `蓄力腾空扑跃`：转身对准落点后蹲蓄力，头朝前抛物线腾空飞扑并伸出双前足落地回弹
  - `赛博雷达脉冲`：发射环形脉冲波并左右扫视机身与口器触肢
- **行为模式切换**：`自主漫步巡逻`、`跟随鼠标陪伴`、`固定原地待命`、`休眠呼吸灯模式`
- **体型调节**：`放大体型 (+)`、`缩小体型 (-)`、`恢复默认大小 (100%)`

## 模块架构

- [`pet.py`](./pet.py)：主程序入口、45 FPS 帧循环、点击/拖拽防抖、右键菜单调度与 `--self-test` 端到端自检
- [`renderer.py`](./renderer.py)：`920×920` 全向无裁切画布、2x 超采样 PCB 荧光机械足、预乘双核高斯辉光、头腹独立枢轴旋转与惯性摆尾合成
- [`win32_window.py`](./win32_window.py)：原生 64-bit `ctypes` Win32 置顶无边框透明分层窗口、DPI 自适应与像素级点击穿透
- [`ik_solver.py`](./ik_solver.py)：基于局部标准空间正反旋的 360° 零翻转多连杆解析逆运动学求解器（`3link` / `coxa_2link_dogleg` / `2link`）
- [`gait.py`](./gait.py)：桌面坐标锚定的 6 足交替三足步态（含原地转身步态预测）、口器触肢微动作合成与腹部角速度惯性摆动
- [`behavior.py`](./behavior.py)：先转向再推进巡航 AI、光标原地转身凝视、360° 全方向四大特技与任意朝向二维弹簧阻尼悬垂物理
- [`assets/rig.json`](./assets/rig.json)：角色骨骼绑定、关节色板与部件局部坐标系定义
